1. **Brand Identity & Aesthetics**
   - High-resolution JANYX EDU HUB logo with emblem (Lotus blossom, cerebral brain, open book).

   - Clean, modern typography using Google Fonts (`Outfit` & `Plus Jakarta Sans`).

2. **Core Promises & Methodology (5 Pillars)**
   - **1-on-1 Personalized Attention:** Tailored lesson plans designed around each student's strengths and areas for improvement.

   - **Verified & Passionate Tutors:** Subject-matter experts who mentor, motivate, and inspire.
   - **Borderless Learning:** Live, one-on-one digital classrooms equipped with interactive tools for global students.

4. **Modes of Learning**
   - **Personalized Home Tuition:** Dedicated in-person tutors at your residence.

## 🚀 How to Run & Preview

### Option 1: Using the Built-in Node Server (Recommended)
```bash
npm start
```
Then open your browser at:
`http://localhost:3000`

### Option 2: Direct Browser Opening
Simply double-click `index.html` in your file explorer to open it directly in Google Chrome, Microsoft Edge, or any browser.
